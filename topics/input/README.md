# Input

Input problems often cross several systems, so the maintained article stays with the broader UI material while this subject provides a direct route to it.

- [Targeting, action execution and ownership](../ui/input-action-boundaries.md): permission to target an object, the action it performs and the ownership change that follows.

Managed call traces can establish gates and dispatch order. They do not prove pointer projection, collider reachability, frame timing or whether a player can complete the action in the running game.
