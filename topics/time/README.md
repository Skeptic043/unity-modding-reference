# Time

These articles focus on ownership of shared Unity time state rather than treating a matching numeric value as proof of which system controls it.

- [Time-scale ownership](timescale-ownership.md): inspect native writers and lifecycle markers before restoring or taking over a value that matches the mod's selection.

The [Sailwind sleep and pause case](https://github.com/Skeptic043/sailwind-technical-reference/blob/main/docs/research/time/time-scale-and-sleep-ownership.md) applies this distinction to one game's transition paths.

Static ordering and managed fixtures do not establish live transition timing, physics behavior or gameplay acceptance.
