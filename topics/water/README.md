# Water

Focused findings for water integrations and HDRP water systems. Each article states whether its evidence comes from documentation, installed source or runtime observation.

- [Crest CPU Query integration limits](crest-cpu-query-integration.md): documented package requirements and unsupported query features, distinct from runtime proof.
- [HDRP runtime water-excluder construction](hdrp-runtime-excluder.md): the renderer and material setup beyond the `WaterExcluder` component.
- [HDRP spectrum wind-speed units](hdrp-spectrum-wind-units.md): the unit conversion used by HDRP 17.6 spectrum code.

The HDRP pages are bounded to Unity 6000.6.0f1 and HDRP 17.6.0 installed source. The Crest page is bounded to official documentation inspected on 2026-09-15. None of these pages claims live gameplay, visual acceptance, headless compatibility or package compatibility beyond the stated evidence.
