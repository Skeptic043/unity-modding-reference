# Physics

These articles separate pose publication, force laws and failure checks from the visible result that first suggested a physics limit.

- [Authoritative pose before support queries](support-pose-before-contact.md): compare `Rigidbody`, `Transform` and child-station poses before judging first contact or continuous support.
- [Operating limits from forces and failures](operating-limits-from-forces-and-failures.md): derive a bounded envelope from runtime mass, active force contributors and actual failure checks.

The Sailwind [boat mass and load-limit](https://github.com/Skeptic043/sailwind-technical-reference/blob/main/docs/research/physics/boat-mass-and-load-limits.md) and [buoyancy](https://github.com/Skeptic043/sailwind-technical-reference/blob/main/docs/research/physics/buoyancy-and-spawn-height.md) cases retain the game-specific values and applications.

Source inspection, controlled fixtures and static models answer different questions. None alone establishes physical stability, performance or gameplay acceptance.
